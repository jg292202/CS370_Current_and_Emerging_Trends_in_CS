# CS370_Current_and_Emerging_Trends_in_CS

## Project Reflection: Pirate Intelligent Agent (Deep Q-Learning)
For this project, I worked with a Jupyter Notebook that contained the starter framework for a pirate-themed intelligent agent navigating a grid-based environment to find treasure. The provided code included the environment setup, the game loop, and the structure of the neural network model. My main task was to complete the Q-Training Algorithm section, where I implemented the deep Q-learing logic that allowed the pirate agent to learn through exploration, exploitation, and iterative updates to its Q-network. I wrote the training loop, the memory replay mechanism, the epsilon-greedy strategy, and the code responsible for updating the model based on the agent's experiences. By the end, the agent was able to successfully learn a path to the treasure through repeated episodes of trial and error. 

Working through this project helped me connect the dots of the course material to the broader field of computer science. At its core, computer sciennce is about desining systems that solve problems efficiently, reliably, and ethically.  Reinforcement learning is just one example of how computational thinking can be applied to real-world challenges by breaking a problem into smaller components, defining clear rules and constraints, and iteratively improving a solution based on feedback. This project reinforced the importance of approaching problems in a methodical manner.  By understanding the requirements, analyzing the behavior of the system, experimenting with parameters, and refining the solution until it behaves as expected, I was able to successfully complete the project. 

It also highlighted the ethical responsibilities that come with building intelligent systems. Even in a simple game environment, it's easy to see how the design of rewards, training data and model behavior can influence outcomes. In real applications, those decisions can affect users, organizations, and entire communities.  As a computer scientist, I have a responsibility to ensure that the systems I build are trasparent, fair, and aligned with the needs of the end user. That includes considering data privacy, avoiding unintended bias, and making sure the technology supports human decision-mmaking rather than replacing it. This project was a great opportunity for me to apply reinforcement learning concepts in a hands-on way while also reflecting on the larger role of computer scientists in shaping responsible technology.
